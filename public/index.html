● Claude Free (limited), Pro, Team, Enterprise
▾
1
Web (claude.ai)
Click + in chat → Connectors → Manage Connectors → Add custom server URL. Paste the MCP URL.
2
Desktop App
Settings → Developer → Edit Config. Add to mcpServers:
{
  "mcpServers": {
    "threejs-editor": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "YOUR_MCP_URL"]
    }
  }
}
3
Claude Code CLI
claude mcp add --transport http threejs-editor YOUR_MCP_URL

get_coderead

Read the current Three.js scene source code from the editor.

Returns: { code, lineCount, lastModifiedBy }
update_codewrite

Replace the entire Three.js scene code. Must define scene, camera, and animate function.

Input: { code: string }
patch_codewrite

Insert, replace, or delete specific lines. More surgical than update_code.

Input: { startLine, endLine?, newCode }
get_scene_inforead

Analyze scene code and return structured summary of objects, lights, and materials.

Returns: { objects, lights, materials, hasAnimation }
add_objectwrite

Add a new 3D object to the scene with geometry, material, and positioning.

Input: { type, position?, material?, name? }
remove_objectwrite

Remove an object from the scene by variable name.

Input: { name: string }
get_errorsread

Check if the current scene code has any runtime errors from the 3D preview.

Returns: { hasErrors, errors }
screenshotread

Capture a screenshot of the current 3D preview as a base64 PNG.

Input: { width?, height? }
